# ApexBank Mobile & E-Wallet Application QA Portfolio
This repository showcases a **production-grade Software Quality Assurance lifecycle** for a high-security Mobile Banking & E-Wallet application operating on Android & iOS.

The methodology fully adheres to the **IEEE 829 Standard for Software Test Documentation** and focuses heavily on high-risk financial workflows, negative scenarios, and real-world mobile interruptions.

## 🛠️ Tech Stack & Methodologies Checked
* **Domain:** Fintech / Banking Sector
* **Documentation Standard:** IEEE 829 Standard (Test Plan -> Test Cases -> Bug Log -> TSR)
* **Testing Types:** Black-box, Functional, Regression, Interruption, Mobile Security (Session Management)
* **Test Design Techniques:** Equivalence Partitioning, Boundary Value Analysis (applied to transaction limits).
